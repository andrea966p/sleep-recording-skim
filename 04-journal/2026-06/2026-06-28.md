## The DEFINITIVE plug map (slip-ring colour → C3410 pad → signal)

| C3410 pad | Slip-ring colour | Signal |
|---|---|---|
| 0 | red | EEG frontal-L (`+`) |
| 1 | black | EEG parietal-L (`−`) |
| 2 | yellow | EMG L (`+`) |
| 3 | blue | EMG R (`−`) |
| 4 | brown | dura **frontal-R** — recorded re-ref / spare |
| 5 | purple | **nothing** — spare line, resined + plugged to pad 5, no electrode behind it |
| 6 | orange | copper coil = **environmental-noise** reference |
| `GND` bus | green | dura **parietal-R** = **animal tissue ground** |
| `REF` | — | (empty) — bipolar → no brain reference |

**Map by slip-ring colour + signal, never tether colour** (tether uses a different convention).

### What changed from earlier drafts
- **Ground = slip-ring GREEN** → bus → `GND` (earlier draft wrongly had orange = ground).
- **Copper/env = ORANGE → pad 6** (earlier had magenta).
- **dura frontal-R = BROWN → pad 4** (earlier put it on pad 5).
- **pad 5 = PURPLE = nothing** — dead spare line, still resined + plugged, carries no signal → **deselect, never record.**

## Three decisions

**1 — Frontal/parietal labels were backwards, corrected.** Green = right **parietal (caudal)** dura pin = animal ground; the right **frontal** dura pin is the **brown / pad 4** line. Verify physically which right dura pin the green wire sits on before powering.

**2 — dura frontal-R recorded on pad 4 (brown).** A real tissue electrode, but green (its right-side partner) is consumed as ground → can't form a right-hemisphere bipolar pair → recorded **single-ended on pad 4** = optional software re-reference (Radiens Paired Reference, manual p70).

> [!important] Three "reference-ish" things — do NOT merge
> - **pad 4 (brown)** = optional **biological** re-ref (recorded, subtracted in software).
> - **pad 6 (orange)** = **environmental** ref (copper coil; cable shield cut at the mouse, sees only EM).
> - **hardware `REF` pad** = EMPTY (RHD2216 bipolar → no brain-reference input).
> Pad 4 does NOT go to the chip `REF` pad.

**3 — pad 5 (purple) = nothing, but still built.** Resined + plugged to pad 5 with no electrode behind it → a wired-but-dead input → floats/rails → **deselect in channel-select.** Exists only to fill the strip position.

> [!note] pad 5 means opposite things across eras
> Old 2-mice = M1 green **ground**; new single-mouse = **purple / nothing (deselect)**. Callouts flag this in the guides.

## Build to the map (new slip-ring)
Resin-potted → not re-pinnable → **build new.** On the new build: **green → ground bus**, **orange → pad 6**, **brown → pad 4**, **purple → pad 5**, red/black/yellow/blue → 0/1/2/3. ⚠️ Don't compensate green/orange at the busbar/tether end — a later corrected slip ring would stack swaps and re-break the ground.

**DMM-verify before power:** green → bus → `GND` → chip GND must beep (the broken one); brown → pad 4; copper → orange → pad 6; purple → pad 5 only; red/black/yellow/blue → 0/1/2/3. Pads 4/5/6 NOT continuous with `GND`; `REF` empty. Then stream **raw** → railing should stay collapsed; filter only after.

**Channel-select:** recorded pads = **0,1,2,3,4,6** (skip pad 5). Non-contiguous → select explicitly. Pairs: 0−1 left EEG, 2−3 EMG; pad 4 standalone re-ref; pad 6 env-noise subtract.
