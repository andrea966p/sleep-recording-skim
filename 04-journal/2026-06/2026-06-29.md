- **Grounding good:** pad 0 sits at 225 µV pk-pk (not 12 mV) and unwired 19–31 rest at ~37 µV floor. If the animal still floated, *every* channel would rail together. They don't → green→bus→`GND` holds.
- **EMG open, not the rig:** computed the bipolar pair from raw stream — **EMG 2−3 = RMS 2466 µV, does NOT cancel.** If both EMG tips sat in the same muscle they'd share common-mode and 2−3 would shrink to tens of µV. ### ⚠️ Incident — SDK impedance RPC crashed allegoserver
The SDK has **no impedance-measure RPC** — only `GetIntanImpedance` (a getter for the last GUI sweep), and Intan impedance needs acquisition **paused** (injects a 1 kHz test current). Calling it mid-stream via raw gRPC (`stub.GetIntanImpedance(ImpedanceRequest(port=3))`, auth via `new_server_channel`) returned `Socket closed` and **crashed allegoserver — port 50051 refused** (the known crash, see [[signal-mapping-guide]] §10). Recovery: operator restarted Allego → re-set mode `XDAQ_ONE_REC` → re-set sample rate 1000 → re-select channels; session daemon auto re-paired. **Lesson: never call `GetIntanImpedance` while streaming. Measure impedance only from the GUI Impedance module** (Module Drawer → Signal Collection → **Impedance**, boxed-`Z` icon, manual p27); the SDK getter is read-only and even then is fragile mid-stream.
