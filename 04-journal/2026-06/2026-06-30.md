## C. ⭐ PREP — first 2-mice-per-headstage plug (correct grounding) — after lunch
First time running **2 mice on one RHD2216 headstage** with the grounding lesson applied. Use the existing legacy 2-mice map; the NEW part is grounding both animals correctly.

### Sensor map (already on disk — do NOT rebuild)
- `/home/skimlab/radix/devices/hstg__usrdef_2mice32.hstg` + `probe__usrdef_2mice32_probe.prb` (full-32). Map: **M1 = native 0–3 → sites 1–4** (EEG±/EMG±), **M2 = native 8–11 → sites 5–8** (EEG±/EMG±), other natives parked sites 9–32.
- Load: Electrodes → Port D → "Use local devices" → Headstage `Usrdef 2mice32`, Probe `Usrdef-2mice32-Probe` → Apply.
- **Channel select trap:** with the custom map loaded, chips are labeled by **SITE**, so select **sites 1–8** (NOT D/1–D/8, NOT sites 9–12). M2 = sites **5–8**, not 9–12 (see [[signal-quality-and-grounding]]). Deselect all first, select sites 1–8 explicitly.

### ⚠️ Grounding for 2 mice — the key new thing
- One RHD2216 = **one GND**. Both mice share it. **BOTH animals must tie their ground electrode to the common bus → GND**, or the ungrounded one floats and rails (the whole saga). Each implant now has its own animal-ground dura/bone pin (the green line) per the surgical requirement.
- So: **mouse-1 green ground AND mouse-2 green ground → busbar → 1 wire → C3410 `GND`.** Both animals end up on the shared amplifier common (electrically coupled — normal/accepted for multi-animal bipolar rigs).
- **Before power (DMM beep, both):** mouse-1 green → bus → GND → chip GND = beep; mouse-2 green → bus → GND = beep. Confirm the busbar physically accepts both ground wires and both are continuous to GND. `REF` empty (bipolar). [[grounding-reference-noise-concepts]] §5 method.

### Plug checklist (mirror of [[2026-06-29]], adapted)
1. Stop session daemon if EEG-only/no video: `sudo systemctl stop neurosurveillance-session.service`.
2. Allego mode `XDAQ_ONE_REC`, Port D = 32; sample rate 1000 (re-set after mode).
3. Load `Usrdef 2mice32` map (above); select **sites 1–8**.
4. CAR/reference OFF (bipolar, don't click Add Filter on referencing).
5. **Stream first** → Monitor: BOTH mice's EEG pairs sit mid-lane, **no global railing**. If one mouse rails on all its channels → that animal's ground isn't tied → recheck its green→bus→GND.
6. **Impedance sweep** (GUI Impedance module, boxed-Z, Module Drawer; acquisition paused) on all 8 sites — good electrode ≈ 0.1–1 MΩ, open ≈ ≫5 MΩ. Catch dead electrodes before recording. **Never call SDK `GetIntanImpedance` while streaming — it crashed allegoserver.**
7. Record raw 1 kHz when both mice look clean. Readback via numpy / convert to EDF as in §A.

### Expectations / risks
- Most likely snag = **one mouse not grounded** (its green not reaching the shared bus) → that mouse rails while the other is clean. Tells you which ground to fix.
- EMG may again read open if any implant's EMG wasn't seated in muscle (this is the lesson from the single-mouse 7 MΩ). Impedance-check tells you per electrode.
- Storage if this becomes a 12-mouse / 3-day baseline: see [[2026-06-29]] storage note (~125–250 GB; all-32-pri saved; confirm 625 Hz selectable, else 1 kHz ×1.6).
