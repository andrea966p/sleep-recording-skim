## Issues

- Ghostty terminal type (`xterm-ghostty`) not recognized by `nano` on Raspberry Pi OS — workaround: `export TERM=xterm-256color`
- Daemon restart failed with `systemctl --user` — service is system-level (`/etc/systemd/system/`), needs `sudo systemctl restart neurosurveillance-session`. Fixed vault docs (cheatsheet, workflow, new-pi-setup) to use correct commands.
- `wlan0` interface still visible on Pi 2 (state DOWN) despite `dtoverlay=disable-wifi` in boot config — interface is disabled but not fully removed. Minor, no action needed.

### Backend + Frontend 4-Camera Code Fixes

Infrastructure was deployed earlier today (Frigate sees all 4 cameras, daemon config has all 4), but the **code** still had hardcoded 2-chamber assumptions. Fixed all instances:

**Backend changes:**
- `daemon.py` — `_handle_session_start()` now derives `chambers_to_start` dynamically from `self.session_manager.cameras` instead of hardcoded `["0", "1"]`

- `session_manager.py` — fallback default cameras updated to include all 4 chambers

**Frontend changes:**

**Reference config:**
