## Work Log

### UI Tech Stack Decisions

Made all design decisions for the session controller frontend. The daemon backend is complete (committed `dd705ad` on Feb 20), so the focus shifted to building the UI that researchers will use to interact with it.

**Decisions made:**

| Decision | Choice | Rationale |
|----------|--------|-----------|
| App type | **Tauri desktop app** | Lightweight native shell, smaller than Electron, good Linux support |
| Frontend framework | **React + TypeScript** | Largest ecosystem, Project IDX knows it well |
| Styling | **Tailwind CSS + DaisyUI** | Pre-styled components, fast to build, dark theme out of the box |
| UI complexity | **Full dashboard** (5 panels) | Researchers need status visibility, not just a form |
| Camera preview | **Embedded Frigate restream** | Snapshot polling via `http://192.168.0.50:5000/api/<camera>/latest.jpg` |
| Real-time updates | **HTTP polling** (1.5s interval on `/api/status`) | No backend changes needed; daemon only has REST API |
| Session history | **Simple table with click-to-expand** | Sufficient for reviewing past sessions |
| Handoff format | **Single markdown document** | Self-contained prompt for the AI agent |

**Dashboard panels decided:**
1. **Session Setup** — metadata form (mouse ID, recording type, chamber, user name). Locks during active recording.
2. **Live Status** — recording state (red pulsing dot when ON), Radiens/MQTT connection, active session timer
3. **Camera Preview** — side-by-side live feeds from both chambers, active chamber highlighted
4. **Session History** — expandable table of past sessions (newest first)
5. **System Health** — daemon/Frigate/MQTT/Radiens connection badges

### Session Daemon Deployment

Deployed the session daemon to the ASUS PC. Key steps and discoveries:

**Radiens blocker resolved:**
- The `radiens` package was **not** pre-installed (previous journal entry was wrong)
- Found it on PyPI as `radiens` v4.0.0 — standard `pip install radiens`
- `AllegoClient()` constructor prompts for NeuroNexus cloud auth (Cognito) by default
