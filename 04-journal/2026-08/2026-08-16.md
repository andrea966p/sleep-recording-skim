## Work Log

### Moved my day to day work off the recording machine, onto the ThinkPad

**TL;DR.** `e10ubuntu` is the machine that runs the recordings, so I stopped using it as
my desk. Work now happens on the ThinkPad laptop and I reach the rig over SSH. Three
things had to be true and all three now are: the vault syncs to the laptop, Claude Code
has the same memory and skills there, and I can run commands on `e10ubuntu` without
opening a remote desktop session. Full writeup with the numbers is in
[[01-infrastructure/multi-machine-work-setup]]; this entry is the short version plus
what I deliberately did not do.

While setting it up I found what almost certainly killed the vault the last time. The
Syncthing folder had **NO FILE VERSIONING**, so a delete on any machine propagated
everywhere with zero undo, and it had **NO IGNORE RULES**, so the live 114 MB `.git`
directory was being copied between machines while the obsidian-git plugin committed into
it on both ends. Both are fixed now: staggered versioning with 365 day retention, and
`/.git` excluded through a `.stignore` file. I tested it rather than assuming: a delete
on the laptop propagated in about five seconds AND left the whole file recoverable in
`.stversions/` on `e10ubuntu`. That is the exact operation that destroyed the vault
before, and it is now survivable.
