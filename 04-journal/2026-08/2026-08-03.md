## 🔴 Thresholds were guesses. Re-derived from 1,137,955 epochs.

Audited every constant against the pooled data instead of trusting it.

| constant | was | now | basis |
| --- | --- | --- | --- |
| `RAIL` | 6300 µV (guess) | **6389.6 µV** | `0.195 µV/LSB × 32767`. MEASURED: max\|sample\| is 6389.8 µV on all 8 channels = 16-bit ADC full scale |

Epidural screws in rodents are **5–50 kΩ at 1 kHz**; ≤10 kΩ confirms contact.

## 🔴 REM is not reliably separable — stop reporting it

The 80th-percentile rule forces REM to 20% of sleep. An independent Otsu cut on
theta/delta gives 24–48% of sleep. **The literature value for mice is <10%.**
Both rules land far above it, so neither is a measurement. Report **WAKE vs
NREM** and REM's **order** (entered from NREM). Do not report a REM share.

## 🔴🔴 We have only ever measured HALF of each electrode pair

Andrea's question: if the RHD2216 is bipolar and does the difference before the
data reaches XDAQ, how can we measure single-electrode impedance at all?

**Answer: the chip can, and Radiens won't.**

Datasheet Register 5 has a dedicated bit, **`Zcheck pol sel`**:

> "The RHD2216 has two independent input pins for each amplifier, so an extra
> register called Zcheck pol sel is provided to select between the positive and
> negative amplifier input pins during electrode impedance testing. When
> Zcheck pol sel is set to zero … the **positive input terminal (inX+)** … set to
> one … the **negative input terminal (inX−)**."

The differential subtraction is irrelevant to this — the test injects current
into **one input pin** and reads the resulting voltage back through that same
amplifier. Measurement happens at the input, not after the subtraction.

**But Radiens exposes no polarity control.** Andrea pushed back on whether I had
checked the API docs properly — I had not, I had only checked the installed
package and the GUI PDF. Redone exhaustively against **four** sources: installed
`radiens`, the Radiens Technical Documentation PDF, the online `radiens-core` API
reference, and the **`radiens-core` 0.0.8 wheel source** pulled and unpacked.

```python
# radiens_core/_converters/_impedance.py
ImpedanceRequest(port=port_to_proto(p))          # port is the ONLY field

# radiens_core/models/impedance.py
class ImpedanceValue(BaseModel):
    ntv_chan_idx: int
    magnitude_ohm: float
    phase_deg: float                              # three fields. no polarity.

# radiens_core/allego_client.py
def get_intan_impedance(self, port: FlexPort) -> Impedance:   # the ONLY impedance method
```

- **One impedance method on the entire `AllegoClient`**, taking a port and nothing else.
- **No polarity field** in request, response or protobuf.
- 🔑 **No Intan register-write path at all.** The register methods that exist
  (`load_all_mosi`, `transmit_mosi`, `read_wire_out`, `flash_sinaps`) are
  **Sinaps-probe specific** and cannot reach the RHD chip. **There is no back door
  — we cannot set `Zcheck pol sel` from Radiens by any route.**

Chip default is `pol sel = 0`, so **every number we have is the positive input,
and the negative electrode of every pair has never been measured.** (Strictly: it
is proven we see exactly *one* of the two; that it is `inX+` follows from the chip
default and is very likely but not separately confirmed.)

This makes the vendor ask concrete: **`Zcheck pol sel` is a single register bit
NeuroNexus already drives, and the API offers no way to reach it.** That is a
feature gap on their side, not a usage error on ours — worth raising on the
Kontex thread alongside the other open items.

### Why this matters

**It explains B1** — 0.133 MΩ, best EEG impedance in the fleet, then fully open
for 21.7 h. If that is `inX+` alone, `inX−` could have been open the whole time
and the sweep would look perfect. A differential amp with one open input gives
exactly what we saw.

**It explains why impedance predicted class but not yield.** Our own relation is
`differential_60Hz ≈ common_mode × electrode_Z_imbalance` — an imbalance
*between the two inputs*. We have only ever seen one. The predictive quantity was
never measurable.

### The fix

1. **DMM each C3410 pad against the animal `GND` pad** — free, no animal contact,
   gives per-electrode continuity **including every negative electrode**. This is
   now the top action: it is both the solder-vs-electrode discriminator *and* the
   only way we currently have to see the negative side at all.
2. Ask Kontex/NeuroNexus to expose `Zcheck pol sel` — one register bit they
   already drive.
3. Check whether the Open Ephys GUI exposes polarity (unverified).

Written up in [[electrode-connection-state-test]].

## ✅ "Are we sure `/1`,`/2` is right?" — yes, and now we know exactly why

Andrea asked whether selecting only `port/1`,`port/2` (and `/33`,`/34`) is
actually correct. Checked it properly instead of repeating the vault.

The **definitive pad map** ([[grounding-reference-noise-concepts]] §2) already
carries the answer in its own `+`/`−` labels:

| C3410 pad | colour | signal | chip pin | amp | Allego |
| --- | --- | --- | --- | --- | --- |
| 0 | red | EEG frontal-L **(+)** | `in0+` | amp 0 | **`/1`** |
| 1 | black | EEG parietal-L **(−)** | `in0−` | amp 0 | **`/1`** |
| 2 | yellow | EMG L **(+)** | `in1+` | amp 1 | **`/2`** |
| 3 | blue | EMG R **(−)** | `in1−` | amp 1 | **`/2`** |

Datasheet confirms the structure: *"16 amplifiers having independently accessible
differential inputs (in0+, in0–, in1+, in1–, …)"*, and *"32 biopotential
amplifiers … Only channels 0-15 are active in the RHD2216"* — which also finally
explains why Allego shows 32 slots per port for a 16-channel chip.

**So `/1` = frontal-L − parietal-L = the bipolar left EEG, and `/2` = EMG-L −
EMG-R = the bipolar EMG. The whole montage is two channels. Selecting `/1`,`/2`
(+`/33`,`/34`) is correct.**

> "Recorded pads = 0,1,2,3,4,6 … select pads explicitly"
> "Differential pairs **in software**: 0−1 = left EEG, 2−3 = EMG"

Both are pre-08-01 leftovers sitting in the page labelled *definitive*. You do
not select pads — you select **amplifiers**, and the subtraction happens **in
hardware before the ADC**. Anyone following that line would re-introduce the
exact bug that cost weeks. Struck and replaced with the pad→pin→amp table.

### 🔑 And it makes the impedance blind spot concrete

With `pol sel = 0`:

| channel | impedance number is | **never measured** |
| --- | --- | --- |
| `/1` "EEG" | **EEG frontal-L** (pad 0, `in0+`) | **EEG parietal-L** (pad 1, `in0−`) |
| `/2` "EMG" | **EMG L** (pad 2, `in1+`) | **EMG R** (pad 3, `in1−`) |

So every "EEG impedance" we have ever quoted is **the frontal electrode
specifically**; the parietal has never been measured once.

⭐ **This probably reconciles the old "frontal open, parietal fine" observation.**
Those two numbers were far more likely `/1` and `/2` — the EEG amp's `+` input
versus the EMG amp's `+` input — mislabelled as frontal vs parietal by the wrong
channel map. That is our current finding in different words: **EEG open, EMG
working.** Strong inference, not proven, but it removes the last evidence that
ever supported the frontal-sinus story.

### Scope note

`/3`,`/4` are **half-wired on the single-mouse 8-pin rig** (pad 4 = real dura
frontal-R vs open; pad 6 = copper env-ref vs open) but **genuinely empty on the
current 8-mouse rig**, which fits only 4 electrodes + ground per animal. The
impedance sweeps agree (`/3`,`/4` read the same as the no-wire control). Both
statements now carry their scope in the docs.
