# 2026-07-01 — MAJOR CLOSURE: ONE headstage per mouse (not 2 mice/headstage); dual-headstage acquisition validated; "broken headstage" root cause found (HDMI top SPI socket is dead)

> [!success] TL;DR — the day in five results
> 1. **"2 mice per Intan headstage?" → NO — one headstage per mouse.** The two mice are forced onto a **single shared ground** (both animals' ground wires → one bus → one `GND` pad on the headstage). Standard practice is **one ground/reference per animal**; a shared ground is not electrically independent and can couple the animals. The step-by-step unplug test (§6) confirmed the mice can only be separated by removing tether **+** slip-ring **+** ground — they are entangled through the common ground. Since **dual headstage now works** (result 3), the answer is one headstage per mouse.
> 2. **The multi-day "headstage won't enumerate" mystery is SOLVED.** The **top SPI socket of the HDMI/SPI adapter is non-functional** — a headstage on the top socket is never detected, regardless of XDAQ port, adapter unit, headstage, or SPI cable. **Use the bottom socket.** The suspected-dead headstage was always fine.
> 3. **Dual-headstage acquisition works** — two headstages on the two **bottom** SPI sockets enumerate as **Port A (32 ch) + Port B (32 ch) = 64 ch**, **each with its own ground = one mouse per headstage, fully independent.** Scalable to **more mice by adding headstages**.
> 4. **Reference/chip settled:** we are **RHD2216 bipolar**, hardware `REF` empty **by design** — not a fault. (An earlier "RHD2132 / shared reference" guess was wrong and is retracted below.)
> 5. **Railing decoded:** a railing wired channel = an **OPEN input** (no electrode contact) picking up EMI; a clean channel = a real low-impedance electrode contact. Confirmed A1's clean EEG on a second headstage (RMS 107 µV, proper 1/f delta PSD).
>
> Continues [[2026-06-30]]. Rig electronics are now cleared end-to-end; recording topology = **one mouse per headstage**; remaining work is surgical/electrode-contact.

## 1. Method — how signals were checked

Live signal was pulled straight off the streaming acquisition (no recording needed):

- Snapshot via the Radiens SDK in `/opt/neurosurveillance/venv`: `from radiens import AllegoClient` → `c.set_time_to_cache_head()` then poll `c.get_signals()` for ~6–16 s, concatenating unique cache windows. Values are already **µV**.
- Filtering / PSD / plots in the clean analysis venv `/home/skimlab/eeg-analysis-venv` (numpy 2.5 + scipy 1.18 + matplotlib). The radiens venv cannot run scipy (numpy-2 vs system-scipy clash), so signal pull and DSP are split across the two venvs.
- **Impedance** only from the **Allego GUI, paused** (never the SDK `GetIntanImpedance` while streaming — it crashes allegoserver).

> [!note] Two diagnostic tells used all day
> - **Floor channels = ground indicator.** Natives **17–31 are not broken out on the C3410**, so when the amp common is properly grounded they sit at a quiet **~4–25 µV floor**. If the animal/system floats, *every* channel — including 17–31 — rails ~10–12 mV pk-pk. So: 17–31 quiet ⇒ grounded; 17–31 railing ⇒ float.
> - **Railing wired channel = OPEN input.** An open amplifier input (no low-impedance electrode) picks up mains/EMI and rails. A real electrode contact shorts the pickup and the channel reads signal. (Applies to any open node on the adapter region, whether a dangling slip-ring wire or a bare C3410 pad.)

## 2. ⭐ ROOT CAUSE — HDMI adapter TOP SPI socket is dead

The headstage that "wouldn't enumerate" for days ([[2026-06-29]] item A; `priSigs=0` / `port_num_channels={}`) is **not broken**. Systematic swap testing today isolated the fault to the **top SPI socket of the HDMI/SPI adapter**:

- A headstage whose SPI cable lands on the **top** socket is **never detected**.
- **Independent of:** which XDAQ port is used, **which** HDMI adapter unit (tried **two** different adapters — both fail identically), which headstage, and which SPI cable.
- On the **bottom** socket the same headstage enumerates and streams instantly.

> [!important] Operating rule
> **Always use the BOTTOM SPI socket of the HDMI adapter.** The top socket is non-functional on both adapters we have. This — not a bad headstage, cold joint, or wrong mode — was the real cause of the multi-day enumeration failures. No RMA needed.
> Current working config: **two headstages, each on a bottom SPI socket** of the adapter → Port A + Port B (§7).

Earlier contributing red herrings now retired: wrong Allego mode (`SMARTBOX_PRO`), loose HDMI seating, VDD/GND/SPI-pin bench probing — all real-but-secondary. The decisive variable was the socket.

## 3. Reference / chip — we are BIPOLAR (correction logged)

> [!warning] Retracted mid-day error
> An earlier analysis guessed **RHD2132 (unipolar, one shared reference)** from the `H32EEG` connector name + a web pairing, and built a "floating reference" theory for the railing. **Wrong — it contradicts the vault** ([[grounding-reference-noise-concepts]], [[signal-mapping-guide]]). Our chip is **RHD2216 = bipolar**: every channel is its own **+/−** differential pair, there is **no shared reference line**, and the hardware **`REF` pad is EMPTY by design**. There is no "reference config" to fix. The railing is a **contact/ground** phenomenon (§4–§6), not a reference one.

SDK confirms: Allego exposes DAC/analog-out + channel metadata but **no reference getter** — consistent with `REF` being an unused hardware pin on a bipolar rig.

## 4. Grounding behaviour

### 4a. Swap test → GLOBAL FLOAT (ground not re-made)
After swapping to a **new headstage + new C3410 adapter** and re-plugging mice, **all channels railed, including unwired natives 4–7** (this morning those sat at the 7 µV floor). Per the floor-indicator rule this is a **global float** — the animal-ground path (green → brass bus → new C3410 `GND` pad) was **not reconnected on the new board**. Fix is physical: reconnect green→bus→`GND`, DMM-beep end-to-end; the floor channels then drop back to ~7 µV.

### 4b. Each mouse self-grounds (independent grounds)
Later, with only **D2** connected, removing **A-side mouse's green from the bus** did **not** float the system — floor channels 17–31 stayed at ~4 µV. ⇒ **D2's own green holds its headstage's common independently.** On a shared bus the two greens are **parallel/redundant**; either mouse's ground holds it, and removing one does not float the other. Confirmed again in §7 (both ports grounded on their own mouse's green).

## 5. Railing = OPEN input (mechanism nailed, with a correction)

Two isolation moves proved it:

- Removing a mouse's **tether** while its **slip-ring stayed plugged** → that mouse's channels **kept railing** (dangling slip-ring wires = open antennas).
- Fully disconnecting a mouse's **slip-ring at the C3410** → its channels **still railed**, and bare unwired pads 4,6,7 rail too.

> [!important] Refined statement (earlier "slip-ring is the antenna" was incomplete)
> **Any open input in the adapter region (natives ~0–16) picks up EMI and rails** — via a dangling slip-ring wire *or* a bare C3410 pad alike. Only a **real low-impedance electrode contact** pulls a channel down to signal level. Natives **17–31 stay at floor** because they are **not broken out on the C3410**. So: rail = open/no-contact; clean = real contact.

This explains the recurring signature across **every** mouse-set tested today: exactly **~1 leg contacts cleanly (~55–110 µV), the rest rail** (open). Which leg is good drifts between reads = intermittent contact. Not the chip, not the reference, not the grounding, not 2-mice sharing.

## 6. 2-mice-per-headstage isolation protocol (Diane's D1 + D2, one headstage)

Structured test on one headstage carrying two mice (D1 = natives 0–3, D2 = natives 8–11), known-grounded.

| Step | Action | Result |
|---|---|---|
| 1 | **Both mice** streaming | Each mouse: ~1 clean EEG leg, rest rail. Floor 17–31 quiet (grounded). No global effect. |
| 2 | **Unplug D2 tether** → read D1 | **D1 unchanged** (clean leg + railing legs identical). D2's channels still rail (slip-ring antenna). ⇒ **no cross-coupling.** |
| 3 | **Disconnect D1 slip-ring at adapter** → read D2 | D1 channels **still rail** (open pads, §5). D2 unchanged. |
| 4 | **Remove A-side mouse green from bus** (D2 only) | Floor 17–31 **stayed quiet** ⇒ **D2 self-grounds** (§4b). |

> [!warning] Verdict — do NOT run 2 mice per headstage; use ONE headstage per mouse
> The decisive point is the **shared ground**. Two mice on one headstage put **both animals' ground wires on one bus → one `GND` pad** — a single common ground for two animals. Standard EEG practice is **one ground/reference per animal**; a shared ground means the two animals are **not electrically independent** and can couple through the common ground.
> The unplug sequence shows how entangled they are: Step 2 (unplug D2 tether) left D2's **slip-ring and ground still connected**, so "D1 unchanged" did **not** prove independence — the mice were still sharing the ground at that point. Only after Step 3 (slip-ring off) **and** Step 4 (ground off the bus) is a mouse truly separated. ⇒ you cannot cleanly ground, run, or verify one mouse without the other on a shared headstage.
> **Conclusion: one mouse per headstage.** This is now practical because dual headstage works (§7): 2 headstages = 2 fully-independent mice, each with its own ground; add headstages to scale.

## 7. Dual-headstage acquisition — 64 channels

Two headstages, each on a **bottom** SPI socket → **Port A 32 ch + Port B 32 ch = 64 ch**, fs 1000. (Streaming comes up `S_OFF` after re-enumeration — must click **STREAM** again. `get_signals` returns 64 pri interleaved: **Port A = rows 0–31, Port B = rows 32–63**.)

- **Port A = D1** (D2 disconnected): all 4 legs rail/hi = poor contact on that animal. Floor quiet (grounded via D1's green).
- **Port B = A1** (A2 disconnected): **both EEG legs clean** (EEG_F 109 µV, EEG_P 33 µV), **EMG rails** — A1's exact known signature, **reproduced on a second headstage.** Floor quiet.

### 7a. A1 clean EEG — characterised
Filtered bipolar EEG (B0−B1, 0.5–45 Hz + 50 Hz notch): **RMS 107 µV, pk-pk 709**, rhythmic slow-wave trace, **PSD with proper 1/f falloff, delta-dominant (theta/delta 0.25)** = genuine cortical EEG. 50 Hz clean. (Signal sits mostly on EEG_F; EEG_P ~10 µV.) Figure: `A1_eeg.png` (scratchpad).

### 7b. Contrast — D2 (fresh) marginal leg
D2's only in-range leg (EEG_FR) read RMS ~179 µV with a **flat/broadband PSD** and large intermittent bursts = noisy single-ended contact, its EEG/EMG pairs open. A **fresh** implant can still give poor contact — so contact quality is per-implant, not explained by A2's dried blood. Figure: `mouse_signal.png` (scratchpad).

> [!important] Milestone
> The long-blocked second SPI port now enumerates (once off the dead top socket). **Two headstages simultaneously, 64 ch, each with its own independent ground** → the correct multi-mouse topology: **one mouse per headstage**, scale by adding headstages. This is what makes "one headstage per mouse" (§6) practical instead of a limitation.

## 8. Big conclusions

1. **The acquisition chain is fully validated and cleared** — chip (RHD2216 bipolar), grounding, dual headstage, dual SPI (bottom socket), Allego config. Nothing electronic is blocking recording.
2. **One mouse per headstage — do NOT share a headstage between 2 mice** (shared single ground = not independent, against one-ground-per-animal practice; §6). **Two headstages work together (64 ch)**, each with its own ground → scale to more mice by adding headstages, not by doubling mice on a headstage.
3. **The remaining and only limiter is per-animal electrode contact** (implant quality + connector cleanliness). Good implants read clean (A1 EEG); poor ones rail (open) — independent of the rig.
4. **Two hardware operating rules are now firm:** (a) **bottom SPI socket only**; (b) **animal ground (green) must be re-verified green→bus→C3410 `GND` after any board/headstage swap** (a missed re-tie floats everything).
5. **Diagnostics we can trust going forward:** floor channels 17–31 = ground check; railing wired channel = open contact; impedance is 1 kHz AC and can miss a DC-offset/intermittent leg, so cross-check with the live trace.
