## Reference check — we are BIPOLAR (RHD2216); `REF` empty is correct

> [!warning] Correction — earlier "RHD2132 / shared reference" analysis was WRONG
> An earlier draft of this section guessed **RHD2132 (unipolar, one shared reference)** from the `H32EEG` connector name + a web pairing, and built a "floating reference" theory. **That contradicts the vault and is retracted.** Our chip is **RHD2216 = BIPOLAR** ([[grounding-reference-noise-concepts]], [[signal-mapping-guide]], [[intan-rhd2216-reference]]): every channel is its own **+ / −** differential pair, there is **no shared reference line**, and the hardware **`REF` pad is EMPTY by design** — that is correct, not a fault. There is no "reference config" to fix.

**SDK probe (`/opt/neurosurveillance/venv`):** Allego exposes DAC/analog-out settings + channel metadata but **no reference getter** (RHD `REF` is a hardware pin; on a bipolar rig it is intentionally unconnected). `get_analog_out_settings` = DAC0 monitoring amp ntv0, high-pass off. Signal units confirm AMP = µV.

**Bipolar means the railing is NOT a reference problem.** Per the vault's grounding model:
- **Ground** (green → brass bus → C3410 `GND`) is the DC tie that holds the animal in the amp's ±5 mV window. If the animal floats → **all** channels rail ~10–12 mV pk-pk.
- Today **not all channels rail**: ntv0 (EEG+, pad 0) is clean 69 µV and the **unwired channels sit at the 7 µV floor**. If the animal were floating, those unwired inputs and every channel would rail together. They don't ⇒ **the ground tie is working; the animal is NOT floating.**
- `REF` empty is by design (bipolar) ⇒ not the cause.

> [!important] So what IS railing ntv1/2/3?
> Ground good + REF correctly empty + only pads 1,2,3 pinned while pad 0 is clean ⇒ the fault is on **those specific input legs** (electrode / slip-ring / tether / C3410 pad for pads 1,2,3), not the shared grounding or reference. And it is the **same pads (0 clean; 1,2,3 rail) across two different fresh mice AND yesterday's mice** → the bad legs are in the **rig**, not the animals. This is the "flaky connector contacts" through-line from [[2026-06-30]], now isolated to pads 1,2,3.
> Note: an impedance sweep is **1 kHz AC** and won't catch a large **DC half-cell offset / intermittent junction**, so a leg can read low-Z yet still rail.

### Decisive bench tests (operator, at the rig)
1. **Tap test** (Monitor tab, [[signal-mapping-guide]] §8.2) each of pads 1,2,3 vs pad 0 — confirm which electrode legs actually respond.
2. **DMM continuity** pad 1,2,3 electrode pin → C3410 pad → slip-ring → tether — find the intermittent/high-R leg.
3. **DMM DC offset** electrode→GND for pad 0 (clean) vs pads 1,2,3 (railing) — a large/unstable offset on the bad legs = smoking gun.
4. Confirm green (animal ground) is on the **`GND` bus**, `REF` stays **empty** (bipolar — do not wire it).

### Bearing on "2 mice per board" (bipolar framing)
- **Bipolar RHD2216 has no shared reference to couple animals** — each channel self-references its own +/− pair. So the "two mice share one reference" objection does **not** apply. The real shared resource is the **single `GND` bus** (one ground tie for both animals); memory shows M1 read clean on that shared ground, so shared ground is not automatically fatal.
- **Verdict is still blocked** by the pad 1,2,3 railing, which is present with **one** mouse. Fix the rig legs first; only then does a 2-mice clean/not-clean result mean anything.
