## Reference / headstage architecture check (SDK + Intan/NeuroNexus docs)

**SDK probe (`/opt/neurosurveillance/venv`):** Allego exposes DAC/analog-out settings + channel metadata, but **no software-reference getter**. The RHD reference is the hardware `REF` pin, set in the GUI / on the headstage board — not readable via SDK. `get_analog_out_settings` = DAC0 monitoring amp ntv0, high-pass off. Signal units confirm AMP = µV.

**Headstage:** available-sensor list shows `adaptor_XDAQ_X3SR-H32EEG` (32-ch EEG). NeuroNexus **H32 EEG connector pairs with the Intan RHD2132** chip. ⇒ **almost certainly RHD2132.** ⚠️ Confirm by the chip part number on the physical headstage.

| chip | inputs | reference |
|---|---|---|
| **RHD2132** | 32 **unipolar** amps | **ONE common shared reference line** (all 32 vs same REF) |
| **RHD2216** | 16 **independent differential** pairs | per-pair, best CMRR |

Intan doc facts:
- On the headstage, **REF and GND are tied by a 0-Ω resistor** → REF ≈ GND by default.
- **Floating / bad REF → ALL channels rail** (common-mode saturation) even if electrode impedances read fine.

> [!important] What this tells us about our railing
> - ntv0 reads **clean** → the common REF is **good** (a floating REF would rail all 32, not 3).
> - So on a shared-reference chip, ntv1/2/3 railing while ntv0 is clean = **per-channel input fault on those 3 electrode/wire paths — NOT the reference.**
> - Impedance passed on those sites, but the **impedance test is 1 kHz AC** — it does **not** catch a large **DC half-cell offset** or very-low-frequency drift, which can still rail an AC-coupled amp. Low AC-Z + rails = suspect **electrode DC offset / dissimilar-metal junction / intermittent wire on ntv1,2,3**, not open contact.

### Decisive bench tests (operator, at the rig)
1. **DMM DC voltage** electrode→GND bus for ntv0 vs ntv1,2,3. Clean ntv0 = small mV; railing ones likely show a large/unstable DC offset = the smoking gun.
2. **DMM continuity** each of ntv1,2,3 electrode pin → adapter pad → slip-ring → tether (find an intermittent/high-R junction on those 3 lines specifically).
3. Confirm `REF` handling in the GUI: for unipolar EEG, REF must tie to a real low-impedance reference electrode (or GND via the 0-Ω). Verify green (animal ground) lands on **GND bus**, not REF.
4. Read the **chip part number** off the headstage → RHD2132 vs RHD2216 (settles the 2-mice architecture question below).

### Bearing on "2 mice per board"
- If **RHD2132** (likely): **one common reference for all 32 channels** → two animals would share a single reference → mouse-2 measured against mouse-1's reference = **cross-animal coupling, not independent recordings**. Matches Prof + Intan spec ("one ref/animal"). ⇒ **2 mice per RHD2132 board = not clean; use one board per mouse** (or a bipolar RHD2216 where each pair is independent).
- **But** this is moot until the single-mouse railing is fixed — even one mouse rails 3/4 channels right now. Fix that first, then the 2-mice verdict is meaningful.
