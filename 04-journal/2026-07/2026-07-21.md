# 2026-07-21 — Kontex call (KC Kong) + scale-up decisions

## Kontex video call — outcome (KC Kong, Prof. Kim joining)

Full prep in [[2026-07-21-kontex-kc-call-prep]]; decision thread in [[2026-07-21-acquisition-device-16-32-mice-and-kontex-thread]].

### What KC confirmed / said
1. **Custom "4-socket, 1-MISO-per-socket" port adapter = NOT possible.** This kills Prof. Kim's variant (one MISO per socket → 4 mice per HDMI port on the Core) definitively, from the vendor's mouth. The MISO-pair count is fixed by the box; no adapter reshuffles it into 1-per-socket.
2. **Port Expander (SAdpt-Port-EXP) — KC suggests we TRY it** because it handles the **grounding of each mouse separately** (isolated ground/reference per animal). This is the per-animal isolation we care about for the 60 Hz saga.
3. **Two-XDAQ license limitation ACKNOWLEDGED** — a second XDAQ needs its own software license (confirms the open question; 2× XDAQ = 2× license, and per SyncLink docs each XDAQ → its own PC).
4. **Headstage should be as CLOSE to the mouse as possible.** Our rig's ~**40 cm analog run** (headstage at chamber top → animal) is **a stretch / too long** in KC's view. Flag for the rig redesign — shorter analog run = less noise pickup (ties directly to the 60 Hz/impedance story).
5. **2 mice per Intan adapter board = NOT possible — not even with the Port Expander.** One adapter board = one mouse. ⚠️ Need to pin down exactly which board he meant (C3410 electrode board vs C3442 dual adapter) — see open items.
6. KC **proposed several parts on the Kontex website** to complete the rig — need to go through them.

### The main open technical item
**How to wire 4 Port Expanders to our XDAQ Core Gen-1.** The Core needs **extra adapters** to complete that chain — the Port Expander doesn't just drop in. We need to work out the full parts list and wiring order (Core HDMI → Port Expander → per-EXP-port Intan adapter → RHD2216 headstage), using what's on the Kontex site.

> [!warning] Reminder: Port Expander on the Core does NOT add mice
> Core = 2 MISO pairs/port → only EXP A + B available per port → **2 animals/port × 4 ports = 8**, same ceiling. Buying 4 Port Expanders for the *Core* buys **per-animal grounding isolation on the existing 8-mouse rig** — a test of whether isolation fixes the 60 Hz hum — NOT a path to 16. 16 still needs the ONE+.
