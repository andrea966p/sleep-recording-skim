## What changed

- **Skeleton.** `00-inbox/` (new notes land here and are filed by a wizard), `04-journal/`
  (unchanged), `10-projects/` (hlb-sod1, rig-expansion, rig-bringup, noise-hunt,
  unipolar-lfp), `20-areas/` (eeg-rig, allego, recording-console, eeg-analysis,
  sleep-scoring, nanotag, data-storage, computing, video-nvr), `30-resources/`,
  `90-archive/`, flat `_attachments/`. Map of every move: `_meta/path-map-2026-10-22.tsv`.
- **Links.** 892 path links rewritten to note names before anything moved; 436 files moved
  as pure renames; Obsidian's own link graph compared before and after every step
  (`tools/vault/`). Broken links: 95 → 0 outside the archive.
- **Metadata.** Every note has `type`, `area`, `status` (planned / active / done /
  superseded); journal notes have a one-line `summary`, shown by [[journal.base]].
- **Hubs and truth pass.** One agent per area built its hub, added dated banners where a
  note presents something outdated as current, and logged contradictions in
  `_meta/contradictions/`. Memory-only knowledge (the 60 Hz saga, Allego gotchas, the
  unipolar run, the NS-SD study) now has vault notes.
- **Audits.** Hub claims: 174 of 204 supported, 30 fixed (the "electrodes proven good at
  0.052 MΩ" claim is withdrawn: unwired inputs read 0.051 MΩ). Records: 0 changed beyond
  added callouts. A usability test answered 7 real questions from HOME in 2-5 hops.
- **Code.** `eeg-emg-analysis/core/paths.py` points at this vault's `_attachments/`;
  55 vault-path citations in code, configs and systemd units updated. Tests: 59 + 120 pass.
- **Hygiene.** Local REST API secrets untracked; a live Slack webhook URL removed from a
  note (rotation is on the decisions page); `~/CLAUDE.md` now has the real host facts.
