### 0.3 — Netdata docker-daemon restart alert

New file: `/etc/netdata/health.d/nvr-docker.conf` (loaded via `sudo killall -USR2 netdata`).

**Diagnostic note for future-me:** the obvious first attempt — `on: app.dockerd_uptime` — silently failed to instantiate. Netdata templates match by chart **context**, not chart **name**. The chart `app.dockerd_uptime` has context `app.uptime` and chart label `app_group=dockerd`. The working form:

```
template: nvr_dockerd_restart
      on: app.uptime
chart labels: app_group=dockerd
  lookup: average -10s of uptime
   warn: $this < 300
   crit: $this < 60
   delay: down 5m
```

Same `chart labels:` filter pattern as the existing `nvr_container_down` (filtering `docker.container_state` to `container_name=frigate mosquitto uptime-kuma`).

Status after first evaluation cycle: `CLEAR` with `value: 85708.5 seconds` (= 23.8 h, matching dockerd's restart at yesterday's incident). Will fire `WARN` for ~5 min after the next docker restart, then auto-clear.

Note: also useful to know that `netdata -W reload-health` does **not** exist in Netdata 2.x — the help text directs to `SIGUSR2` (`sudo killall -USR2 netdata`). Recording this here so it doesn't have to be re-discovered.
