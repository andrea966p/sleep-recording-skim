### Frigate Deployment Plan Analysis

Analyzed the 7-step deployment plan against existing vault golden configs (v5.0). Identified the following improvements in the v5.1 plan:

| Change | v5.0 | v5.1 | Impact |
|--------|------|------|--------|
| MQTT | `enabled: false` | `enabled: true` + Mosquitto | Enables Frigate event system |
| Privileged mode | `privileged: true` | `cap_add: CAP_PERFMON` | Much more secure |
| GPU device | `/dev/dri` (entire dir) | `/dev/dri/renderD128` only | Minimal access |
| Per-camera hwaccel | Duplicated on each camera | Global only | Correct — Frigate inherits global setting |
| Graceful shutdown | None | `stop_grace_period: 30s` | Prevents recording corruption |
| RTSP password | `FRIGATE_RTSP_PASSWORD: "CHANGE_ME"` | Removed | Not needed for internal LAN |

**Verdict:** Plan is correct and safe to deploy. No issues found.
