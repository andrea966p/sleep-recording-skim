Andrea, 2026-11-04: a 57 % T1 side share in the HLBNSL NOR (7/9 mice above 50 %, not significant) is not a preference,
and the NOR stays a valid recognition test. Over-discounting it (calling recognition "not established") was wrong.

**Why:** at n = 9 a non-significant bias is noise; treating it as a confound throws away a test that passed its own
location check (spot share rose T1 → T2 in 9/9 mice). Real design gaps (object identity not counterbalanced) stay as one
limitation line, not as a verdict.

**How to apply:** before calling any baseline bias a confound, test it; if it is not significant, report it as a check that
passed. Keep the caveat proportional. Related: [[feedback_report_writing_style]].
